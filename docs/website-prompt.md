# MirrorX0 공식 사이트 제작 프롬프트

아래 내용을 그대로 Antigravity(또는 다른 코딩 AI)에게 전달하면 됩니다.

---

## 프롬프트

MirrorX0라는 윈도우 데스크톱 프로그램의 **공식 배포 사이트**를 만들어줘.
정적 사이트 한 벌(HTML/CSS/JS)이면 되고, 빌드 도구나 프레임워크 없이
바로 열리는 형태로 만들어줘. GitHub Pages에 그대로 올릴 거야.

### 이 프로그램이 뭔지

웹사이트를 통째로 받아서 인터넷 없이 그대로 열어볼 수 있게 해주는 도구야.
비슷한 프로그램으로 HTTrack이 있는데, 그건 20년 넘은 도구라 요즘 웹을 못 따라가.
MirrorX0의 차별점은 이거야:

1. **자바스크립트로 그려지는 사이트도 받는다.**
   HTTrack은 HTML 원문만 읽어서 React/Vue로 만든 사이트를 받으면 빈 껍데기가 나와.
   MirrorX0는 실제 크롬 브라우저로 화면을 그린 뒤에 저장해서, 스타일·이미지까지
   포함된 '진짜 열리는 사본'을 만들어.
2. **두 가지 방식을 골라 쓴다.** 정적 사이트는 빠른 '사이트 미러링',
   자바스크립트 사이트는 '스마트 크롤링'. 버튼 하나로 전환돼.
3. **AI 기능.** "레시피만 받고 장바구니는 빼줘" 같은 문장으로 받을 범위를
   정할 수 있고, 받아온 페이지에서 원하는 데이터만 뽑아 엑셀/CSV로 저장할 수 있어.
4. **로그인이 필요한 사이트도 받는다.** 크롬에 이미 로그인해 둔 상태를 그대로 써.

### 사이트 성격

httrack.com 같은 **공식 사이트 겸 배포 사이트**야. 다만 그것보다 훨씬 현대적이고
군더더기 없이. **블로그, 뉴스, 커뮤니티, 포럼, 후원 같은 건 전부 빼줘.**
꼭 필요한 것만:

1. **첫 화면(히어로)** — 한 줄 설명 + 큰 다운로드 버튼 + 프로그램 스크린샷
2. **왜 이걸 쓰는가** — 위 차별점 3~4개를 아이콘과 짧은 문장으로
3. **HTTrack과 비교표** — 자바스크립트 사이트 / 오프라인 사본 품질 / AI 기능 /
   로그인 사이트 / 최신 UI 항목으로 비교. 과장 없이 사실만.
4. **다운로드** — 윈도우 설치 파일, 버전 번호, 용량, 업데이트 날짜.
   "이전 버전" 링크도 작게.
5. **시작하기** — 설치 → 주소 입력 → 시작 버튼, 3단계를 그림/숫자로 간단히
6. **자주 묻는 질문** — 5개 내외 (무료인가 / 로그인 사이트 되는가 /
   받은 파일 어디에 저장되나 / 맥·리눅스 되나 / 안전한가)
7. **푸터** — GitHub 링크, 라이선스 고지

### 디자인

프로그램 자체가 애플 느낌의 밝고 깔끔한 디자인이라 사이트도 똑같이 가줘.
**흰색 기반 라이트 테마**. 다크 모드는 안 만들어도 돼.

색은 프로그램에서 실제로 쓰는 값 그대로 써줘:

```css
--bg:          #F6F4F1;  /* 페이지 배경 - 아주 옅은 웜 그레이 */
--panel:       #FFFFFF;  /* 카드 배경 */
--panel-warm:  #FCF7F1;  /* 강조용 카드 (웜 아이보리) */
--border:      #E9E5DF;
--accent:      #F97316;  /* 브랜드 오렌지 - 아껴서 써야 함 */
--accent-deep: #DC5A00;  /* 그라데이션 끝 */
--accent-soft: #FFF3E8;  /* 은은한 배경 틴트 */
--accent-text: #C2410C;  /* 흰 배경에 오렌지 글씨를 쓸 때 */
--fg:          #1C1C1E;  /* 본문 */
--fg-muted:    #8A8A8E;  /* 보조 설명 */
--success:     #2FB457;
```

지켜야 할 것:

- **오렌지는 아껴서.** 주요 버튼(다운로드)과 로고 포인트에만. 배경을 오렌지로
  뒤덮지 마. 화면 대부분은 흰색/웜 그레이여야 해.
- 로고는 `Mirror`(먹색) + `X0`(오렌지)로 붙여 쓴 워드마크.
- 카드는 **둥근 모서리(14~18px)** 와 아주 옅은 그림자. 테두리는 1px `--border`.
- 폰트는 한글·영문이 같이 예쁜 걸로 (Pretendard 또는 Noto Sans KR).
  제목은 굵게 크게, 본문은 16px 이상.
- 여백을 넉넉하게. 요소를 빽빽하게 채우지 마.
- 애니메이션은 스크롤 시 부드럽게 나타나는 정도만. 과하면 촌스러워.

### 기술 요건

- 순수 HTML/CSS/JS. React·Tailwind 같은 것 없이. 빌드 단계 없이 바로 열려야 해.
- **반응형** — 모바일에서도 가로 스크롤이 생기면 안 돼.
- 이미지는 lazy loading, 폰트는 `font-display: swap`.
- 접근성: 이미지에 alt, 버튼에 적절한 대비, 키보드 탭 이동 가능.
- SEO: title/description/OG 태그. 한국어 우선(`lang="ko"`)이되
  영어 페이지도 나중에 붙일 수 있는 구조로.
- 파일 구성은 `index.html`, `assets/style.css`, `assets/app.js` 정도로 단순하게.

### 주의

- **없는 기능을 지어내지 마.** 위에 적은 것만 사실이야.
  수상 경력, 사용자 수, 후기 같은 건 만들지 마.
- 다운로드 버전/용량/날짜는 `v0.1.0`, `약 25MB`, `2026-07-28`로 넣어두고
  나중에 고칠 수 있게 한 곳에 모아줘.
- 푸터에 이 문구를 꼭 넣어줘:
  "MirrorX0는 사이트 미러링에 HTTrack 엔진(GPLv3)을 사용합니다."
